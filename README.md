# streams

Скиллы для Claude, которые работают со стримами через расширение **Claude in Chrome**.

## stream-clipper

Находит смешные моменты (30–120 c) в записях стримов на Twitch и Kick:
прогоняет VOD целиком на ускорении, пишет чат-реплей, ищет всплески смеха и «клипни»,
сверяет с клипами зрителей, проверяет каждый момент скриншотами и выдаёт таблицу
с таймкодами и ссылками.

Субтитры и заголовки — следующий этап (см. `stream-clipper/references/next-steps.md`).

### Установка

- **claude.ai / Claude desktop:** Настройки → Capabilities → Skills → загрузить
  `dist/stream-clipper.zip`.
- **Claude Code:** скопировать папку `stream-clipper` в `~/.claude/skills/`.

Нужно установленное и подключённое расширение Claude in Chrome.

### Как пользоваться

1. Впишите своих стримеров в `stream-clipper/streamers.md` (перед упаковкой) или просто
   называйте стримера в запросе.
2. Попросите: «Найди смешные моменты в последнем стриме <стример> на Twitch».
3. Не трогайте вкладку со стримом, пока Claude её прогоняет, и держите её видимой.

### Ограничения

- Claude не слышит звук. Моменты ищутся по реакции чата, клипам зрителей и картинке;
  шутки «только на слух» помечаются как «нужно послушать».
- Стрим длиной 4 часа на скорости x4 прогоняется примерно за час.
- Вёрстка Twitch/Kick меняется; если скрипт не находит чат, Claude подбирает селектор
  сам (см. SKILL.md, шаг 3).
